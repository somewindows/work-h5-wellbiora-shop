# WELLBIORA 跨境 H5 商城设计规范 v0.3

> v0.3 更新（2026-08-23）：四个产品素材全部到位，新增「产品主题色」表；P4 卖点图存在合规高风险文案，详见第九节。

> 本文档是前端开发的**唯一设计依据**。所有页面的色值、字号、圆角、间距、组件样式均以本文档为准，不得自行发挥。
> 版式布局参照 LemonBox 小程序（米白底 + 卡片式 + 大留白），品牌视觉替换为 WELLBIORA 体系。
> 设计基准宽度：375px（iPhone），px 通过 postcss-px-to-viewport 转 vw。

## 一、品牌基础

- 品牌名：WELLBIORA™（字标全大写，™ 上标）
- Logo 图形：四瓣圆角叶片组成的十字形
- Logo 文件（已归档至 `assets/wellbiora/`）：
  - `logo-组合-深绿白底.jpg` —— 图形+字标，用于首页顶部、浅色背景
  - `logo-字标-深绿白底.jpg` —— 纯字标，用于窄空间（导航栏）
  - `logo-白标-深绿底.jpg` —— 反白版，用于深色区块、页脚
  - `logo-黑标-薄荷绿底.jpg` —— 备用版

### Logo 使用规则
- 浅色背景用深绿标，深色背景用白标，禁止改色、拉伸、加阴影
- Logo 四周留白 ≥ Logo 图形高度的 1/2

| 角色 | 色值 | 用途 |
|---|---|---|
| 品牌主色·深墨绿 | `#033B3C` | 主按钮、强调文字、导航选中态、页头页脚 |
| 品牌深色·墨绿黑 | `#022829` | 深色区块背景（品牌故事、页脚） |

| 产品色·谷胱甘肽浅蓝 | `#88BDCB` | P1 产品专属点缀（产品卡图区底色、详情页氛围） |

### 中性色

|---|---|---|
| 页面背景 | `#F7F5F0`（米白） | 全局页面底色 |

| 主文字 | `#1A1A1A` | 标题、正文重点 |
| 次要文字 | `#6B6660` | 描述、辅助说明 |
| 弱提示文字 | `#A8A29A` | 占位符、禁用态 |
| 分割线 | `#EAE6DF` | 卡片内分隔线 |

### 功能色

| 角色 | 色值 | 用途 |
|---|---|---|
| 价格/促销 | `#E6432D` | 售价、立减、促销标签 |
| 成功 | `#2BA471` | 支付成功、有货 |
| 警示 | `#ED7B2F` | 库存紧张、待付款 |
| 错误 | `#D54941` | 表单错误、失败提示 |

### 配色比例原则
- 页面以「米白底 + 白卡片」为骨架（约 70%）
- 深墨绿只用在关键动作和品牌露出（约 20%）
- 促销红只出现在价格和活动标签，不大面积使用
- **禁用 LemonBox 的亮黄色**，那是对方品牌色，不是我们的

## 四、间距与圆角

### 间距刻度（4px 基数）
`4 / 8 / 12 / 16 / 24 / 32 / 48`

- 页面左右边距：12px
- 卡片内边距：16px
- 卡片之间间距：12px
- 模块之间间距：24px
- 大模块（带主标题）间距：32px

### 圆角刻度
- 小元素（标签、小图）：8px
- 卡片、输入框：12px
- 大卡片、图片容器：16px
- 按钮、胶囊：999px（全圆角）

### 阴影
- 卡片默认**无阴影**，靠底色区分层级（米白底 + 白卡）
- 仅底部悬浮栏、弹窗使用：`0 -2px 12px rgba(0,0,0,0.06)`

### 安全区（硬性要求）
- 所有底部固定栏：`padding-bottom: env(safe-area-inset-bottom)`
- 页面容器高度用 `100dvh`，不用 `100vh`（避开微信浏览器地址栏）

## 五、组件规范

### 按钮
| 类型 | 样式 |
|---|---|
| 主按钮 | 深墨绿 `#033B3C` 底 + 白字，全圆角，高 48px |
| 次按钮 | 白底 + 深墨绿 1px 边框 + 深墨绿字，全圆角 |
| 购买栏次按钮（加购物车） | 浅薄荷绿 `#D9EDE2` 底 + 深墨绿字 |
| 禁用态 | `#E5E1DB` 底 + `#A8A29A` 字 |

### 商品卡（产品列表页，两列网格）
- 图区：方形，薄荷绿或产品色浅底（每款产品可用自己的产品色），圆角 12px
- 信息区：品类标签（12px 次要色）→ 产品名（15px/600）→ 价格（20px/700 促销红）
- 右下角圆形「+」加购按钮：深墨绿底白图标，直径 32px
- 角标：新品（品牌绿底白字）、售罄（灰底白字「到货通知」）

### 底部 Tab 导航（4 项）
首页 / 产品 / 购物车 / 我的
- 白底，图标+文字，选中态深墨绿，未选中 `#A8A29A`
- 购物车带红色角标显示数量
- 高度 50px + 安全区

### 详情页底部悬浮栏
- 左：「加入购物车」（浅薄荷绿底） 右：「立即购买」（深墨绿底），全圆角
- 白底栏 + 顶部细分割线 + 安全区适配

### 折叠面板（重要说明 / 注意事项 / 使用禁忌）
- 标题 15px/600 + 右侧箭头，行间 1px 分割线 `#EAE6DF`
- 展开内容 13px/400 次要色

### 表单（地址/实名页）
- 卡片式分组：收货人信息卡 + 支付人信息卡
- 输入项：标签 14px/600 左对齐 + 输入区，底部 1px 分割线
- 提示语：12px 弱提示色（如「跨境清关需要，请填写真实姓名」）
- 重要提示文案用薄荷绿底卡片高亮（如「下单后无法修改地址」）

### 标签
| 类型 | 样式 |
|---|---|
| 新品 | 品牌绿 `#2BA471` 底白字，圆角 4px |
| 促销 | 促销红 `#E6432D` 底白字 |
| 认证类（GMP/ISO/纯素等） | 白底灰边图标徽章，详情页内排列 |

## 六、动效规范

- 统一时长 200–300ms，缓动 `ease-out`
- 页面切换：右进左出 slide（模拟小程序页面栈）
- 加购：按钮缩放反馈（0.95 → 1）+ 购物车角标跳动
- 弹窗：底部上滑进入
- 不做花哨动画，加载用骨架屏

## 八、内容块（Block）类型清单

详情页与首页一律采用「内容块数组 + 前端渲染器」架构，**禁止富文本**。以下为首批块类型，已按 P1 谷胱甘肽素材对照：

### 详情页内容块

| type | 说明 | 对应 P1 素材 |
|---|---|---|
| `hero_gallery` | 主图轮播 | 主图（袋装+条包） |
| `text` | 富文本段落（仅文字） | 产品介绍文 |
| `feature_badges` | 卖点徽章行（2×2 或横排） | 增强吸收/营养保护/提高生物利用度/美味易饮 |
| `nutrition_table` | 营养成分表（三列表格+配料+过敏原+声明） | 营养成分表图（转为结构化数据，不用图片） |
| `ingredient_list` | 主要成分（图片+成分名+描述，纵向排列） | 谷胱甘肽/葡甘露聚糖 |
| `image_card` | 全宽氛围图+叠字（图+标题+副标题） | 白巧克力风味图 |
| `usage_steps` | 食用方法（图标+文字步骤） | 挤入口中或加入饮品/每日 1 袋 |
| `expert_quote` | 专家背书（照片+姓名+头衔+引文+认证标） | Dr. Czibula László 研发背书 |
| `cert_marks` | 认证标志行（GMP/ISO/VEGAN/Made in Europe 等图标） | 各认证图标 |
| `collapse` | 折叠面板（重要说明/注意事项/使用禁忌） | 合规声明 |
| `faq` | 常见问题 Q&A 列表 | — |

### 首页模块

| type | 说明 |
|---|---|
| `hero_banner` | 顶部轮播大图（可跳产品/活动） |
| `notice_bar` | 公告/活动条 |
| `product_grid` | 产品两列网格（数据源可选分类） |
| `brand_block` | 品牌专区（深绿底反白 Logo + 品牌文案） |
| `image_text` | 图文卡（左图右文/上图下文） |
| `cert_wall` | 认证墙（GMP/ISO/Made in Europe 横排） |

> 新增块类型时：先定义 type 和 data 结构 → 写渲染组件 → 再在页面中使用。

## 九、文案合规红线（保健品）

1. 禁止出现：治疗、治愈、预防疾病、消炎、抗病毒、降三高等医疗术语
2. 「解毒 / Detox」类表述谨慎使用，建议改为「参与人体正常代谢」
3. 功效描述只讲成分本身与营养补充，不承诺结果
4. 每个详情页固定展示合规声明（折叠面板形式）：
   「本产品为膳食补充剂，并非药品，不能替代药物。本产品不能用于疾病的预防、治疗或诊断。」
5. 跨境商品标识：详情页需展示「跨境进口商品」相关提示及「下单后无法修改地址」提示
