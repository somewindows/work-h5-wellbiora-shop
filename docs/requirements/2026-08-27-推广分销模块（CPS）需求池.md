# 需求池：推广分销模块（CPS 一级分销）

- **录入日期**：2026-08-27
- **来源**：客户（保税商合作方）提出「B2B 分销板块」想法，希望其他平台/推广者挂链接卖货、给分销商独立账号
- **状态**：🅿️ 需求池暂存，未排期（待 B2C 主链路跑通后再评估，建议二期）
- **评估人结论**：真 B2B 不可行（合规限制）；CPS 一级推广分销可行，中等工作量

---

## 一、需求背景

客户希望不只做自营 B2C，还能让其他平台/渠道推广 WELLBIORA 产品：

- 推广者拥有独立账号
- 通过专属链接推广商品，产生订单后获得佣金
- 货仍从保税仓发（1210 模式不变）

## 二、关键结论：真 B2B 做不了，CPS 推广可以做

### ❌ 真 B2B（商家批量拿货转售）— 不可行

1210 保税备货属于**跨境电商零售进口**，监管上只允许 B2C：

- 每笔订单须三单对碰（订购人/支付人/收货人实名一致），且必须是终端个人消费者
- 受单笔 ≤ 5000 元、个人年度 ≤ 26000 元限额约束
- 保税仓货物**不能批量出仓卖给企业再转售**；批量转售需走一般贸易进口（全额关税增值税），属于另一套业务体系

### ✅ CPS 一级推广分销 — 可行

推广者挂专属链接 → 消费者点链接下单（仍是 B2C 零售，照常实名、照常报关）→ 推广者拿佣金。

- 订单履约链路**完全不变**：君梦 OMS 推送、三单对碰、微信中报关都与现状一致
- 分销只是前置的营销归因层，无技术难点

## 三、预估工作量（基于现有规划架构）

| 模块 | 内容 | 工作量 |
|---|---|---|
| 推广员账号 | 申请/审核，挂现有用户体系，加角色字段 | 小 |
| 推广链接/海报 | 带推广码的分享链接、二维码海报 | 小 |
| 订单归因 | 点击记录来源（localStorage + 下单绑定），归属到推广员 | 中 |
| 佣金规则 | 按商品设佣金比例，订单完成计提，退款回冲 | 中 |
| 结算提现 | 佣金明细、提现申请、打款（MVP 可先人工对账） | 中 |
| 后台管理 | 推广员列表、佣金审核、结算单（并入规划的 admin 后台） | 中 |

原型侧预估新增 2~3 页：推广中心、佣金明细、推广海报。整体为**中等工作量**，重点在运营规则设计而非开发。

## 四、红线与注意事项

1. **只能一级分销**：禁止多级拉下线、团队计酬——微信对多级分销打击严格，三级以上涉传销风险。
2. **H5 裂变能力弱于小程序**：H5 在微信内分享/裂变受限，若主战场是微信群+朋友圈裂变，推广效果需打折扣，选型时权衡。
3. **文案合规连带风险**：推广者自发素材若触碰保健品广告红线（治疗/预防表述），责任会追溯到品牌方，合作协议须明确约束与处罚条款。
