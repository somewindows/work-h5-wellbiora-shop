## 三、设计规范（硬约束，不得自行发挥）

以《H5商城设计规范 WELLBIORA v0.3》为准（随附文件），核心 Token 如下：

- **品牌色**：主绿 `#033B3C`、深绿 `#022829`、薄荷绿 `#D9EDE2`、页面底 `#F7F5F0`、强调红 `#E6432D`（仅用于价格）
- **产品主题色**：见上表。规则——**产品色只用于产品相关点缀（卡片底、图廊底、标签），页面骨架（导航、按钮、底栏）保持品牌绿体系不变**
- **排版风格（V2 方向，已获认可）**：杂志式排版——模块标题为「英文衬线小字（Georgia、全大写、字距 .22em）+ 中文大标题」双层结构；大数字数据网格；深色品牌故事区块
- **图片处理**：白底产品图放在有色底上时用融合处理（multiply 混合），不要出现明显白色矩形补丁
- **Logo**：顶部 logo 要醒目（高度不小于 30px），不要缩得太小
- **素材**：产品图未提供前一律用 `/assets/placeholder/` 占位路径；已有产品图见随附 assets

## 四、移动端硬性要求

1. 适配 iPhone 安全区：固定底栏 `padding-bottom: env(safe-area-inset-bottom)`，底部操作栏不被 Home 指示条遮挡
2. 底部固定栏（Tabbar / 购买栏）高度含安全区，页面底部留白避让
3. 所有可点区域 ≥ 44px

## 五、合规红线（文案不得违反）

1. 商品文案**不得出现疾病治疗、预防、医疗术语**（保健品红线）。可用「日常养护」「状态管理」等表述，禁用「治疗/预防/改善病症/助眠（医疗义）」等
2. 详情页必须保留固定合规声明模块（不可删）：膳食补充剂非药品 / 1210 个人自用 / 实名申报 / 三单一致 / 单笔限 ¥5000、年度限 ¥26000
3. 数据宣称（如「4x 吸收提升」）必须带 * 号和来源脚注

## 六、内容块架构要求（重要）

页面**禁止用一整段富文本堆砌**，必须采用「内容块数组 + 渲染器」结构输出。每个详情页 = 若干有序模块。已定义的块类型：

| type | 用途 | 数据形态 |
|------|------|----------|
| gallery | 顶部图廊（产品浅底色底） | images[] |
| info_rows | 产品档案（规格/成分/产地键值行） | rows[{k,v}] |
| stats | 核心数据网格（大数字 2×2） | items[{n,unit,l,d}] |
| scenario | 适用场景 ✓ 清单 | items[] |
| badges | 配方特点徽章（纯素/无糖…） | items[] |
| image | 整幅素材图 | src |
| nutrition | 营养成分表（文字表格） | head/rows/note |
| nutrition_image | 营养成分表（图片版） | src |

如需新增块类型：先写 type 定义和渲染组件，再用于页面。

## 七、设计任务范围

产出 3 个高保真原型页面（HTML + CSS，单目录，可直接浏览器打开预览）：

1. **首页**：杂志封面式 Hero（品牌主张 + 产品图）→ 公告条（保税仓/实名/限额提示）→ 今日推荐横滑票卡 → 「为什么选择我们」数据网格 → 全部产品双列卡 → 品质承诺图标墙 → 深色品牌故事 → 页脚合规信息 → 底部 Tabbar
2. **产品列表页**：标题区 + 四款产品双列卡（产品浅底色 + 图 + 品名/英文名/规格风味/价格/加购按钮）
3. **产品详情页**：图廊 → 摘要卡（标签/品名/英文名/规格/价格/跨境提示条）→ info_rows → stats → scenario → badges → 素材图 → nutrition → 合规声明折叠 → 底部购买栏（加入购物袋 + 立即购买）

文件命名：`prototype/index.html`、`prototype/products.html`、`prototype/product.html`，样式独立为 `prototype/style.css`。
