# WELLBIORA 后台 P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可供 1–3 位运营人员使用的后台 P0：商品运营、内容发布、订单只读/取消与操作日志。

**Architecture:** `admin/` 是独立 Vue 3 + Element Plus 桌面工程，通过 `/api/v1/admin/*` 调用同一 NestJS 服务。服务端以管理员 JWT 保护全部后台业务接口；商品发布、版本和审计数据持久化在 MySQL，H5 只读取已发布版本。

**Tech Stack:** Vue 3、Vite、TypeScript、Element Plus、Pinia、Axios；NestJS、TypeORM、MySQL 8、Jest。

**Spec:** 本会话已确认的「WELLBIORA 后台 P0 页面规划」；`docs/tech/admin-backend.md`。

## Global Constraints

- 后台仅一个管理员角色；所有 `/admin` 业务接口必须要求管理员 JWT。
- 金额字段始终使用分；身份证、完整手机号、密码及其哈希不得返回前端或写进审计差异。
- 商品基础字段保存立即生效；详情内容须先保存草稿、再发布；发布前执行现有内容块和脚注合规校验。
- 订单 P0 仅管理员只读查询与取消待支付订单；不实现退款、库存同步和君梦真实同步。
- UI 使用 Element Plus 的桌面表格/表单密度，并采用 WELLBIORA 深绿 `#033B3C`、米白 `#F7F5F0`、薄荷绿 `#D9EDE2`。
