## 部署中踩坑与修复（已沉淀回仓库）

1. `migration:run`（TypeORM CLI 指定 `-d data-source.ts`）不读 `.env` → 修复：`data-source.ts` 首行加 `import 'dotenv/config'`（commit `248e5df`）
2. 实体联合类型 `string | null` 未显式声明 `type` → MySQL 报 DataTypeNotSupported → 修复：8 个可空字符串列补 `type: 'varchar'`（commit `a70a790`）
3. 迁移用 `TableUnique`（PG 写法）MySQL 不支持 → 改 `TableIndex({ isUnique: true })`（commit `acfd3c9`）
4. MySQL DDL 隐式提交：迁移中断会留下半成品表，重跑报索引重复 → 处理：删残留表重跑；教训已写入 AGENTS.md「迁移铁律」（commit `3836dbe`）
5. Nginx 服务化后桌面会话 `nginx -s reload` 报 `OpenEvent Access denied` → 改用 `nssm restart WellbioraNginx`，指南 13.4/16.4 已修正（commit `500d123`）
