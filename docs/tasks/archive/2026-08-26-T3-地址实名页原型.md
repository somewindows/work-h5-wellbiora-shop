# T3 · 地址+实名页原型（MVP #6）— 已完成归档

- 完成日期：2026-08-26
- 产出：`designs/h5-shop/address.html`（自包含 HTML，沿用 cart/checkout 设计令牌）
- 页面内容（对照设计规范 MVP #6 + 表单规范）：
  - 收货人信息卡：姓名 / 手机号 / 所在地区（弹层选择演示）/ 详细地址
  - 智能粘贴识别：粘贴整段地址文本 → 演示级解析（手机号正则 + 地区匹配 + 姓名提取 + 详细地址剩余），识别后自动回填
  - 支付人实名信息卡：姓名 + 身份证号（18 位校验，末位可为 X）；「支付人与收货人为同一人」开关默认开，自动同步姓名并禁用输入（三单对碰）
  - 薄荷绿重要提示条：「下单后无法修改地址」；输入项提示语 12px 弱提示色，校验失败红标
  - 底部固定「保存并使用」→ 校验通过后 toast 并返回 checkout.html
  - 演示开关：新增地址（空表单）、身份证号校验失败
- 互链接入：checkout.html 地址卡（有地址/空地址两处）与 mine.html「收货地址」cell 均改为跳转 address.html
- 验证：本地 HTTP 服务（4311 端口）访问 address.html 返回 200
- 遗留点：
  - 地区选择为演示弹层（5 个预设地区），正式版需省市区三级联动组件
  - 智能识别为演示级解析，正式版可用正则 + 地址库或 OMS 侧能力
  - 无地址列表页（多地址管理），MVP 先单地址
