# T8 服务端首期（2026-08-29）

## 产出

- 新建 `server/` NestJS + TypeScript 工程，统一 H5 前缀为 `/api/v1`，成功响应为 `{ code: 0, data }`，业务异常统一返回 `{ code, message, data: null }`。
- 商品与首页接口：`GET /home`、`GET /products`、`GET /products/:id`；数据与 `frontend/mock/` 对齐，包含 4 款 SKU、内容块数组、数据脚注和固定合规声明。
- 认证接口：`POST /auth/sms-code`、`POST /auth/login`、`GET /auth/wechat-silent`。开发环境验证码仅输出到服务端日志；Redis 管理验证码、5 分钟有效期、5 次尝试和手机号/IP 限频；登录以 MySQL 用户表持久化并签发 JWT，手机号脱敏返回。
- MySQL 8/Redis 7 的 Docker Compose、TypeORM `users` 迁移、Dockerfile、`.env.example` 和本地启动文档。
- 设计与实现计划：`docs/superpowers/specs/2026-08-29-t8-server-foundation-design.md`、`docs/superpowers/plans/2026-08-29-t8-server-foundation.md`。
