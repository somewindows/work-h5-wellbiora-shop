# admin 首页数据概览（P2，2026-09-17 完成）

> 自 `docs/requirements/2026-09-16-后台功能完善规划.md` P2 条目转入并完成。纯只读聚合，无迁移、无支付逻辑改动，未走对抗性评审（评审关仅针对支付/退款/回调）。

## 产出

- `GET /admin/stats/overview`：今日/昨日（订单数、支付单数、支付金额）、待发货数、退款中笔数、近 7 天订单趋势（按天补零，含今天）
  - 支付金额口径 = paid_at 落在当日且 paymentStatus IN (paid/refunding/refunded)，金额 **实付优先** `COALESCE(payer_total_fen, total_fen)`
  - 日界 = 服务器本地时区；MySQL 趋势分桶用 `DATE_FORMAT(created_at,'%Y-%m-%d')`（避免 mysql2 把 DATE() 转 JS Date 造成时区偏移）
- admin 前端：`/overview` 数据概览页（四张统计卡含昨日对比 + 纯 CSS 柱状图，不引图表库）；`/` 重定向改到 /overview；菜单顶部加「数据概览」（Odometer 图标）；待发货卡片跳 `/orders?status=ship`（订单列表顺手支持 route.query.status 初始化）
