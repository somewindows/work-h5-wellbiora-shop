# 商品图片上传（P2，2026-09-17 完成）

> 自 `docs/requirements/2026-09-16-后台功能完善规划.md` P2 条目转入并完成。零新增 npm 依赖（multer 类型用本地最小声明 `server/src/types/multer.d.ts`）。

## 产出

**server**
- `POST /admin/uploads`（AdminJwtAuthGuard + FileInterceptor）：MIME 白名单 jpg/png/webp/gif（不符 40003）、5MB 上限（Nest 把 MulterError LIMIT_FILE_SIZE 转成 PayloadTooLargeException 413，控制器级过滤器统一回落 400+40003）、文件名 = randomUUID + **从 MIME 映射**的扩展名（不信任用户文件名，防路径穿越）；返回 `{ url: '/assets/uploads/<uuid>.<ext>' }`；审计 `upload_image`
- `UPLOAD_DIR` env：缺省 `./uploads`（dev，已 gitignore），生产挂进 production-guard 必需项（示例 `D:\www\wellbiora\uploads`）
- `main.ts` 加 `useStaticAssets(uploadDir, { prefix: '/assets/uploads/' })`（dev 兜底；生产 Nginx `^~` 先命中）；frontend/admin 的 vite proxy 各加 `/assets/uploads`

**admin 前端**
- 公共组件 `ImageUrlInput.vue`（缩略预览 + 上传按钮 + 保留手填），接入：商品新建/编辑的卡片图、内容块编辑器图片类字段（blockSchemas 新增 `isImageStringField`/`isImageArrayField`，只对 src/image/images 键替换，纯文本 string 字段不动）
- gallery stringArray 每行补「上移/下移」排序

**部署文档**：指南 3.2 加 `mkdir uploads`、10.2 .env 清单加 UPLOAD_DIR、80/443 两 server 块加 `location ^~ /assets/uploads/`（独立目录 alias + nosniff；**robocopy /MIR 发布会清空 site/h5，上传目录必须独立**）、17.3 备份加 uploads 目录
