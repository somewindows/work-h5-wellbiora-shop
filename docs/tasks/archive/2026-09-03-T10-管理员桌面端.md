## 产出

- 新建 `admin/`：Vue 3 + Vite + TS + Element Plus（全量引入）+ Pinia + Vue Router + Axios，端口 5174，`/api` 代理到 `localhost:3000`。
- 页面：登录 `/login`、商品列表 `/products`（搜索/筛选/分页/新建对话框）、商品编辑 `/products/:id`（基础信息表单 + 内容块编辑 Tab）、订单列表 `/orders`（状态 Tab/关键字/日期范围/海关拦截醒目标记）、订单详情 `/orders/:orderNo`（三层状态并排/事件流时间线/同步/取消/退款）、操作日志 `/audit-logs`（筛选/分页/before-after JSON 查看）。
- 内容块编辑器 `src/components/blocks/`：15 种 type（服务端 `CONTENT_BLOCK_TYPES` 同为 15，任务书写 16 是 text 重复）schema 驱动表单；排序/禁用 hidden/删除/添加；草稿-线上差异提示；保存草稿/发布（二次确认+服务端校验错误展示）/回滚（二次确认）；JSON 只读预览；未知 type 兜底 JSON 编辑。
- 对接 `feat/admin-init` 的 `/api/v1/admin/*` 全部接口，类型与服务端 DTO 一一对齐。

## 安全措施落点

- token 只存 sessionStorage，无日志打印；401/40101 自动清会话跳登录并带 redirect。
- 路由守卫；全项目零 v-html（JSON/备注一律 `<pre>` 文本渲染）。
- 取消/退款/发布/回滚全部二次确认，`confirm:true` 仅由确认按钮回调构造。
- 金额分↔元统一走 `utils/format.ts`（Math.round，覆盖 19.99 浮点边界用例）。
- 仅 `.env.example`，无真实密钥；冒烟后临时 `server/.env` 已删。
