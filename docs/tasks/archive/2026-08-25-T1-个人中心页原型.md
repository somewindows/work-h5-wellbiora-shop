## 设计决策（用户已确认）
- 范围：只做「我的」单页；订单列表/详情仍归 T4
- 页面底部带「为你推荐」模块（4 款 SKU 全量 2×2 网格）
- 不做优惠券入口；会员等级/积分/钱包/任务中心/邀请分销等重运营模块全部裁剪

## 页面结构（自上而下）
1. 深墨绿用户信息区（登录/未登录两态，演示开关切换）
2. 我的订单卡：待付款/待发货/待收货/待评价/退款售后五态 + 查看全部订单，待办角标可演示
3. 服务与支持：收货地址（含跨境实名提示）、联系客服（底部弹层：9:00–23:00 + 复制微信号）、协议与规则（底部弹层：用户协议/隐私政策/个人信息收集清单）
4. 为你推荐：2×2 商品网格，＋号加购联动 Tabbar 购物车角标
5. 页脚合规小字：品牌 + 欧洲制造 + 1210 保税备货
