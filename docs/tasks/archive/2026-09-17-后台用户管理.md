# 后台用户（会员）管理（P1，2026-09-17 完成）

> 自 `docs/requirements/2026-09-16-后台功能完善规划.md` P1 条目转入并完成；禁用/启用功能已与负责人确认要做。

## 产出

**server**
- users 表加 `disabled` 列（迁移 `1710000012000-add-user-disabled.ts`，便携 MySQL run/revert/run 已验）
- `GET /admin/users` 列表（手机号脱敏/昵称/微信绑定/实名状态/订单数/累计消费，keyword+注册时间范围+分页）＋ `GET /admin/users/:id` 详情（加实名姓氏脱敏、地址数、年度跨境额度占用——复用 R06 `sumOccupiedYearlyFen` 口径，limitFen 共用 order.service 导出的 `YEARLY_LIMIT_FEN`）＋ `POST /admin/users/:id/disable|enable`（confirm 二次确认、重复操作 40002、审计 `disable_user`/`enable_user`）
- 累计消费口径 = paymentStatus IN (paid/refunding/refunded) 的 SUM(total_fen)，新仓储方法 `summarizeByUsers`（一条 GROUP BY）；admin 订单列表查询加 `userId` 筛选供用户详情内嵌
- 禁用三道拦截：发码前查（40301）、登录双保险、`JwtAuthGuard` 持旧 token 全接口拒绝（用户不存在 → 40101；顺带收紧：guard 现在校验 token 对应用户必须存在）
- 结构：`AdminUsersModule` 独立模块（避免 UsersModule↔OrdersModule 循环依赖）；OrdersModule/ProfileModule 补仓储 exports 并加 register() 记忆化

**admin 前端**
- 「用户管理」菜单 + 列表页（搜索/时间范围/分页）+ 详情页（额度卡、基本信息、内嵌订单列表跳订单详情、禁用/启用走 480px el-dialog 二次确认）
