## 关键决策

- 后台用 Element Plus（桌面端），与 server 同 NestJS 服务，不与 H5 前端混用 Vant
- 商品/首页内容全部后台可配，草稿+发布+回滚；新增块类型是唯一需要开发介入的场景
- 订单状态三层分离：本地主状态 / 支付状态（微信回调）/ 履约状态（君梦轮询，原始状态码落库）
