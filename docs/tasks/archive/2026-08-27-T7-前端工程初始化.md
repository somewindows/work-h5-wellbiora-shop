# T7 · 前端工程初始化（归档 2026-08-27）

## 产出

`frontend/` 工程从零到可运行：Vue 3 + Vite + TS + Vant 4 + TailwindCSS 3 + Pinia + Vue Router（hash）+ Axios + Swiper，postcss-px-to-viewport-8-plugin（375 基准）。

- **骨架**：vite/ts/tailwind/postcss 配置，设计 token 进 tailwind.config（brand 色系 + 产品色），全局样式含安全区/100dvh/480px 限宽
- **类型层** `src/types/`：ContentBlock 联合类型（详情 8 种 + 首页 8 种块）、Product/ProductDetail（产品档案为基础字段）、CartItem/Order/Address/UserInfo，金额一律分（Fen 后缀）
- **mock 层** `mock/`：products/home/orders/misc，数据搬自原型 data.js/data-v2.js/orders-data.js，价格已换算为分
- **API 层** `src/api/`：`VITE_USE_MOCK=1`（.env.development）切换 mock/真实后端，接口路径与 `docs/tech/api-contract.md` 一致；含 createOrder（mock 由勾选购物车生成待付款订单）
- **组件** `src/components/`：TabBar / ProductCard / SectionHead / PriceText + `blocks/` 块渲染器 16 件（BlockRenderer type 分发，未知 type 跳过不白屏；详情页须传 `context="detail"`）
- **9 页全部实现**：首页 / 产品列表 / 商品详情 / 购物车 / 结算 / 地址+实名 / 订单列表 / 订单详情 / 我的 / 登录，视觉 1:1 对照 V3 原型，全链路可走通（浏览 → 加购 → 结算 → 下单 → 订单）
- **文档**：`docs/tech/content-blocks.md` 2.2 登记了 4 个新首页块类型（notice_bar / product_rail / cert_wall / brand_block）
