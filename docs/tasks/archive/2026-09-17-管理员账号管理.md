# 管理员账号管理（P1，2026-09-17 完成）

> 自 `docs/requirements/2026-09-16-后台功能完善规划.md` P1 条目转入并完成。

## 产出

**server**
- `admin_accounts` 加 `role`（super/admin）/`disabled`/`must_change_password` 三列（迁移 `1710000013000`，up 内 `UPDATE` 存量账号为 super——存量即种子超管；便携 MySQL run/revert/run 已验，含存量行升级验证）
- 角色模型：`super` 可管理账号，`admin` 只能改自己密码；播种账号 role='super'
- `POST /admin/auth/change-password`：任何登录管理员改自己密码（旧密码错误 40101、新密码 12-128 位 40003、新旧相同 40002，成功后清 mustChangePassword）
- 超管专属（service 内按 actor.id 回查库校验，不信任 JWT 角色）：`GET /admin/accounts` 列表、`POST /admin/accounts` 新建（生成 16 位 hex 一次性临时密码仅本次响应可见 + mustChangePassword=true）、`POST :id/disable|enable`（禁自己 40002、最后一个可用超管保护 40002）、`POST :id/reset-password`（禁重置自己）。全部 confirm:true 二次确认 + 审计（**快照绝不含密码/哈希**）
- 安全加固：`AdminJwtAuthGuard` 回查库——禁用管理员旧 token 立即 40101；mustChangePassword 期间除 change-password 外一律 40302「请先修改密码」；登录响应带 role/mustChangePassword；禁用账号登录 40301
- 新错误码 40302 = 权限不足/需先改密（管理员侧）

**admin 前端**
- 顶栏改用户名下拉（修改密码/退出登录）；新增「管理员」菜单（仅超管可见）+ 账号列表页（禁用/启用/重置密码/新建，临时密码大号等宽展示 + 复制 + 仅显示一次警告）
- `/change-password` 页；路由守卫强制改密重定向、非超管访问 /accounts 弹回 /products

## 遗留点

- **服务器部署需跑 `migration:run`**（admin_accounts 加三列，存量账号自动升级 super）
- 临时密码为 16 位 hex，无大小写/符号复杂度要求（如需更强策略另定）
- `GET /admin/accounts` 无分页（管理员量级小）
